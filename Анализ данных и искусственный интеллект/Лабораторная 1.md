## 0. Подготовка и данные

```python
import numpy as np

np.set_printoptions(suppress=True)   # числа без экспоненциальной записи
```

## 1. Список и вектор. Зачем нужен NumPy

- **Список** (`list`) — встроенный тип Python. Может содержать элементы разных типов: числа, строки, другие списки.
- **Вектор NumPy** (`numpy.ndarray`) — упорядоченный набор чисел **одного типа**. Элементы лежат в памяти последовательно, одним блоком.
- **Вектор** — одномерный однородный массив данных. `numpy.ndarray` — основной тип данных NumPy.

```python
price_list = [7750.0, 8550.0, 2200.0, 6550.0, 4100.0]   # список
price_vec  = np.array(price_list)                        # вектор из списка
```

### 1.1. Семантика операций

> [!important] Главная идея
> Одна и та же запись операции для списка и для вектора означает **разное**.
> - Для `list` операции отражают логику структуры данных (повторить, склеить).
> - Для `ndarray` операции соответствуют **алгебре векторов и матриц**.

| Выражение | Список | Вектор |
|---|---|---|
| `x * 2` | список повторяется 2 раза | каждый элемент умножается на 2 |
| `x + x` | списки склеиваются | элементы складываются попарно |
| `x + 100` | `TypeError` | 100 прибавляется к каждому элементу |

### Пример: перевод цен в рубли

Для списка нужен цикл, для вектора — одна операция:

```python
RATE = 100.0

# список: цикл
price_rub_list = []
for p in price_list:
    price_rub_list.append(p * RATE)

# вектор: одна операция
price_rub_vec = price_vec * RATE
```

### 1.2. Время вычислений

Одна векторная операция выполняется намного быстрее цикла по списку — на больших данных разница на порядки (в ноутбуке замеряется перевод в рубли 1 000 000 цен через `time.perf_counter()`).

```python
big_vec  = np.arange(1_000_000, dtype=float)
big_list = big_vec.tolist()
```

### 1.3. Объём памяти

- **Список** хранит *ссылки* на отдельные объекты-числа (каждое число — отдельный объект Python).
- **Вектор** хранит *сами числа* одним блоком.
- Размер вектора в байтах — атрибут `nbytes`; размер списка — `sys.getsizeof(list)` плюс размеры всех элементов.

> [!summary] Отличия вектора NumPy от списка
> 1. Все элементы **одного типа** (в списке — любые).
> 2. Элементы лежат в памяти **одним блоком** → меньше памяти.
> 3. Операции **поэлементные и векторные** (алгебра), без циклов → намного быстрее.

## 2. Создание и индексация массивов

### 2.1. Создание массивов

| Функция | Результат |
|---|---|
| `np.array(список)` | массив из элементов списка |
| `np.arange(start, stop, step)` | числа от `start` до `stop` (**не включая**) с шагом `step` |
| `np.linspace(start, stop, num)` | `num` равноотстоящих чисел от `start` до `stop` (**включая**) |
| `np.zeros(n)`, `np.ones(n)` | `n` нулей, `n` единиц |

```python
np.array([2011, 2014, 1998])
np.arange(2010, 2021, 2)         # 2010, 2012, ..., 2020
np.linspace(0, 100_000, 5)       # 5 значений от 0 до 100 000
np.zeros(4); np.ones(4)
```

> [!tip] arange vs linspace
> `arange` задаётся **шагом** (правый конец не входит), `linspace` задаётся **количеством точек** (правый конец входит).

### Атрибуты массива

| Атрибут | Смысл |
|---|---|
| `shape` | форма: число элементов по каждой оси |
| `ndim` | число осей |
| `size` | общее число элементов |
| `dtype` | тип элементов |

Примеры разной размерности:

| Объект | Пример | Особенность |
|---|---|---|
| вектор | `price` | одна ось, `shape = (N,)` |
| скаляр | `np.array(2011.)` | ноль осей, `ndim = 0`, `shape = ()` |
| матрица | `np.array([[211., 11.], [1, 2]])` | две оси, `shape = (2, 2)` |
| многомерный | `np.array([[[[True, False]]]])` | 4 оси, `dtype = bool` |
| с пропуском | `np.array([[[[np.nan]]]])` | `nan` — число с плавающей точкой, `dtype = float64` |

### 2.2. Индексация вектора

- Нумерация с **0**.
- Отрицательный индекс отсчитывается **от конца** (`-1` — последний).
- Срез `a[i:j]` включает элементы с номерами от `i` до `j - 1`.
- Срез с шагом: `a[::k]`.

```python
price[0]          # первый элемент
price[-1]         # последний
price[:5]         # элементы 0..4
price[-4:]        # последние 4
price[10:15]      # элементы 10..14
price[::10_000]   # каждый 10 000-й
```

### 2.3. Матрица «записи × признаки»

Векторы признаков объединяются в двумерный массив:

- **строка** матрицы — запись (автомобиль);
- **столбец** матрицы — вектор признака.

```python
X = np.column_stack((year, distance, engine, price))   # столбцы: год, пробег, объём, цена

X.shape          # (число записей, число признаков)
X[0, :]          # запись 0 (вся строка)
X[:5, 3]         # первые 5 значений столбца 3 («цена»)
X[0, 3]          # цена записи 0
X[:3, :]         # первые 3 записи
```

> [!note] Индексация матрицы
> `X[строка, столбец]`. Двоеточие `:` означает «все элементы по этой оси».

### 2.4. Условная индексация (отбор по условию)

Сравнение вектора с числом даёт **логическую маску** — вектор `True`/`False` той же длины.
Индексация маской `a[mask]` оставляет только те элементы, где в маске `True`.

Условия объединяются операторами:

| Оператор | Смысл |
|---|---|
| `&` | и |
| `\|` | или |
| `~` | не |

> [!warning] Скобки
> Каждое условие обязательно заключается в скобки: `(year < 1970) & auto`.

```python
mask = price > 10_000
mask.sum()            # True считается как 1 → число подходящих записей
price[mask]           # цены больше 10 000

# противоречивые записи: автоматическая коробка до 1970 г.
suspicious = (year < 1970) & auto
suspicious.sum()
X[suspicious]         # маска применяется к строкам матрицы

year[year < 1970]     # годы до 1970
price[auto]           # цены автомобилей с АКПП
price[~auto]          # цены автомобилей с МКПП
```

Альтернатива маске — `np.where(условие)`, возвращает номера подходящих элементов: `price[np.where(year < 1970)]`.

### 2.5. Пропуски

- Отсутствующее значение обозначается `np.nan` (*not a number*).
- Проверка — `np.isnan(a)`, возвращает логическую маску.

```python
missing = np.isnan(engine)
missing.sum()             # число пропусков
X[missing]                # записи с пропуском
engine[~missing]          # значения без пропусков
```

## 3. Базовые операции

### 3.1. Операции вектора с числом

Операция выполняется над **каждым** элементом, результат — вектор той же длины.

```python
engine_l  = engine / 1000   # объём в литрах
price_rub = price * RATE    # цена в рублях
```

### 3.2. Операции двух векторов (поэлементные)

Операция выполняется над парами элементов с одинаковыми номерами. Векторы должны быть **одной длины**.

```python
price_per_cm3 = price[:5] / engine[:5]   # цена на 1 см³ двигателя
price[:5] + price[:3]                    # ValueError: разная длина
```

> [!warning] Размерности массивов должны совпадать
> ```python
> a = np.ones((3, 1))   # вертикальный: shape (3, 1)
> b = np.ones(3)        # вектор:       shape (3,)
> a + b                 # НЕ вектор из 3 чисел, а матрица 3×3
> a.T + b               # a.T — shape (1, 3), результат — (1, 3)
> ```
> - `a.T` — **транспонирование**: из вертикального массива делаем горизонтальный.
> - Если формы разные, NumPy «растягивает» массивы (*broadcasting*), и результат может оказаться не тем, что ожидается. Всегда проверяй `shape`.

### 3.3. Линейная комбинация векторов

Каждый вектор умножается на число, результаты складываются:

```python
a = np.array([1.0, 2.0, 3.0])
b = np.array([10.0, 20.0, 30.0])

2 * a + 0.5 * b + 1     # [2*1 + 0.5*10 + 1, 2*2 + 0.5*20 + 1, 2*3 + 0.5*30 + 1]
np.abs(a - b)           # модуль разности (поэлементно)
```

### 3.4. Поэлементное умножение и скалярное произведение

**Поэлементное умножение:** `a * b` — вектор из произведений элементов с одинаковыми номерами.

**Скалярное произведение** двух $N$-мерных векторов

$\mathbf{a} = \{a_0, a_1, \dots, a_{N-1}\}$ и $\mathbf{b} = \{b_0, b_1, \dots, b_{N-1}\}$:

$$\mathbf{a}\cdot\mathbf{b} = \sum_{i=0}^{N-1} a_i b_i = a_0 b_0 + a_1 b_1 + \dots + a_{N-1} b_{N-1}$$

Для двумерных векторов: $\mathbf{a}\cdot\mathbf{b} = x_1 x_2 + y_1 y_2$.

```python
np.dot(a, b)    # скалярное произведение
a @ b           # то же через оператор @
```

> [!note] Результат
> `a * b` даёт **вектор**, `np.dot(a, b)` / `a @ b` даёт **одно число** (сумму поэлементных произведений).

**Угол между векторами:**

$$\angle(\mathbf{a},\mathbf{b}) = \arccos\left(\frac{\mathbf{a}\cdot\mathbf{b}}{\sqrt{|\mathbf{a}|^2\cdot|\mathbf{b}|^2}}\right)$$

где квадрат длины вектора $|\mathbf{a}|^2 = \mathbf{a}\cdot\mathbf{a} = a_0^2 + a_1^2 + \dots + a_{N-1}^2$.

### 3.5. Агрегирование

Функции агрегирования вычисляют **одно число** по всему вектору.

| Функция | Результат |
|---|---|
| `sum`, `mean`, `median` | сумма, среднее, медиана |
| `min`, `max` | минимум, максимум |
| `argmin`, `argmax` | **номер** минимального / максимального элемента |

```python
price.mean()
np.median(price)
price.min(), price.max()

i_max = price.argmax()    # номер самого дорогого автомобиля
X[i_max]                  # вся запись этого автомобиля
```

> [!important] Пропуски и агрегирование
> При наличии `nan` обычный `mean` возвращает `nan`.
> Для вычисления без учёта пропусков — функции с префиксом `nan`: `np.nanmean`, `np.nanmax` и т.д.
> ```python
> engine.mean()       # nan
> np.nanmean(engine)  # среднее без пропусков
> ```

#### Ось агрегирования `axis` (для матрицы)

| Значение | Агрегирование | Результат |
|---|---|---|
| `axis=0` | по записям (вдоль строк) | одно значение на **каждый признак** |
| `axis=1` | по признакам (вдоль столбцов) | одно значение на **каждую запись** |

Для матрицы `X` смысл имеет только `axis=0`: складывать год, пробег и цену одной записи бессмысленно.

```python
np.nanmean(X, axis=0)   # средние по признакам
np.nanmax(X, axis=0)    # максимумы по признакам
```

> [!tip] Среднее против медианы
> Если среднее цены заметно **больше медианы**, в данных есть небольшое число очень дорогих автомобилей (выбросы справа). Среднее на них реагирует сильно, медиана — почти нет.

## 4. Применение: линейный прогноз и ошибка

В итоговом задании ноутбука векторные операции применяются для предсказания цены.

**Линейная комбинация признаков** (раздел 3.3), считается сразу для всех записей:

$$\hat{p} = w_{age}\cdot age + w_{engine}\cdot engine + b$$

- $\hat{p}$ — прогноз цены, евро
- $age$ — возраст автомобиля, лет (`CURRENT_YEAR - year`)
- $engine$ — объём двигателя, см³
- $w_{age}$, $w_{engine}$ — коэффициенты признаков
- $b$ — смещение, евро

**Средняя абсолютная ошибка (MAE):**

$$MAE = \frac{1}{n}\sum_{i=1}^{n}\left|\hat{p}_i - p_i\right|$$

- $n$ — число записей, $p_i$ — фактическая цена, $\hat{p}_i$ — прогноз
- В NumPy: `np.mean(np.abs(price_pred - price))`
- Базовое сравнение: прогноз «для всех записей — средняя цена»; хорошая формула даёт MAE меньше.

> [!note] Обучение модели
> Подбор коэффициентов по данным называется **обучением модели**. Обучение регрессии разбирается в следующих лабораторных курса.

> [!tip] Очистка данных перед моделью
> Перед построением модели записи с противоречиями отсекаются логической маской (разделы 2.4–2.5): убираются пропуски, нереалистичные объёмы двигателя и цены, подозрительные пробеги. Маска применяется ко всем векторам одинаково, чтобы они остались согласованными по длине.

## 5. Шпаргалка

| Задача | Код |
|---|---|
| вектор из списка | `np.array(lst)` |
| числа с шагом | `np.arange(a, b, step)` |
| N точек от a до b | `np.linspace(a, b, N)` |
| форма / оси / размер / тип | `.shape`, `.ndim`, `.size`, `.dtype` |
| склеить векторы в столбцы | `np.column_stack((v1, v2, ...))` |
| элемент матрицы | `X[i, j]` |
| строка / столбец | `X[i, :]` / `X[:, j]` |
| маска по условию | `a[a > 10]`, `a[(c1) & (c2)]`, `a[~c]` |
| сколько `True` | `mask.sum()` |
| есть ли пропуск | `np.isnan(a)` |
| среднее без `nan` | `np.nanmean(a)` |
| номер min / max | `a.argmin()` / `a.argmax()` |
| агрегирование по признакам | `np.nanmean(X, axis=0)` |
| скалярное произведение | `np.dot(a, b)`, `a @ b` |
| транспонирование | `a.T` |

## 6. Вопросы для самопроверки

> [!question]- Чем вектор NumPy отличается от списка Python?
> Все элементы одного типа; хранится одним блоком памяти (экономнее и быстрее); операции поэлементные/векторные, без циклов.

> [!question]- Что возвращает `price > 10000`? Как выбрать подмножество записей?
> Логическую маску (`True`/`False`) той же длины, что и `price`. Подмножество выбирается так: `price[price > 10000]`; для матрицы — `X[mask]` (маска применяется к строкам).

> [!question]- Что обозначают строка и столбец матрицы `X`?
> Строка — одна запись (автомобиль), столбец — вектор одного признака (год, пробег, объём, цена).

> [!question]- Почему `engine.mean()` возвращает `nan`? Как посчитать среднее без пропусков?
> В `engine` есть пропуски (`nan`), а любая арифметика с `nan` даёт `nan`. Решение: `np.nanmean(engine)` или предварительно отфильтровать `engine[~np.isnan(engine)]`.
