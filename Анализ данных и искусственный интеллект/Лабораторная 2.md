# Pandas: введение — теория

> [!abstract] О чём конспект
> Загрузка табличных данных в `DataFrame`, осмотр, индексация (`loc`, `iloc`, маски, `query`) и предобработка: дубликаты, пропуски, новые столбцы, удаление выбросов, редкие категории, сохранение. Данные те же, что в прошлой лабораторной: продажи автомобилей на вторичном рынке Молдавии (`cars.csv`).
>
> Предыдущая тема: [[Анализ данных - NumPy (теория)]]. Маски и операции со столбцами в Pandas работают по тем же правилам, что и в NumPy.

## 1. Что такое Pandas

**Pandas** — библиотека Python для анализа данных. Табличные данные (`.csv`, `.tsv`, `.xlsx`) удобно загружать, обрабатывать и анализировать с помощью SQL-подобных запросов.

В связке с библиотеками визуализации (`Matplotlib`, `Seaborn`, `Plotly`) и математической обработки (`NumPy`, `SciPy`) даёт широкие возможности визуального анализа таблиц.

### Две основные структуры

| Структура | Что это |
|---|---|
| **`DataFrame`** | двумерная таблица; каждый столбец содержит данные **одного типа**. Строки — признаковые описания объектов (записи), столбцы — признаки. Можно представлять как словарь столбцов с индексами |
| **`Series`** | одномерный индексированный массив данных фиксированного типа (один столбец) |

```python
import pandas as pd
import numpy as np
```

## 4. Индексация

### 4.1. Выбор столбцов

```python
df['AutoTransmission']                  # один столбец → Series
df[['AutoTransmission', 'Price(euro)']] # список столбцов → DataFrame
```

> [!note] Series или DataFrame?
> Одинарные скобки `df['A']` → `Series`. Двойные `df[['A']]` или `df[['A', 'B']]` → `DataFrame`.

Разделение на входные данные и целевую переменную:

```python
df_X = df[[x for x in df.columns if x not in ['Price(euro)']]].copy()  # все столбцы, кроме цены
df_y = df[['Price(euro)']].copy()                                      # только цена
```

`.copy()` создаёт независимую копию, чтобы изменения не влияли на исходную таблицу.

### 4.2. `loc` и `iloc`

| Метод | Индексация | Формат |
|---|---|---|
| `loc` | по **названию** (метке) строки/столбца | `df.loc[строки, столбцы]` |
| `iloc` | по **порядковому номеру** | `df.iloc[строки, столбцы]` |

> [!important] Концы срезов
> - В `loc` срез `a:b` **включает** оба конца (`loc[0:5]` — строки с метками 0…5).
> - В `iloc` срез работает как в Python: правый конец **не входит** (`iloc[0:5]` — позиции 0…4).

Примеры `loc`:

```python
df.loc[:, 'AutoTransmission']                 # весь столбец
df.loc[1437, 'AutoTransmission']              # конкретное значение
df.loc[0:5, ['AutoTransmission']]             # срез строк, список столбцов
df.loc[:, 'Make':'Style']                     # срез столбцов по названиям
df.loc[69, :]                                 # строка 69 → Series
df.loc[[69], :]                               # строка 69 → DataFrame
df.loc[322:1437, :]                           # срез строк
df.loc[227:229, 'Make':'Fuel_type']           # срез и строк, и столбцов
```

Примеры `iloc`:

```python
df.iloc[0:5, 0:3]    # первые 5 строк, первые 3 столбца
df.iloc[0:1]         # первая строка (DataFrame)
df.iloc[-1:]         # последняя строка
```

> [!tip] Одна строка: Series или DataFrame
> `df.loc[69, :]` возвращает `Series`, а `df.loc[[69], :]` (индекс в списке) — `DataFrame` из одной строки.

### 4.3. Логическое индексирование (маски)

Форма записи: `df[P(df['Name'])]`, где `P` — логическое условие, проверяемое для каждого элемента столбца. Результат — `DataFrame` только из строк, где условие истинно.

```python
df[df['AutoTransmission'] == False]   # автомобили с механикой
df[df['Year'] < 1970]                 # выпущенные до 1970 года
```

Комбинации условий:

| Оператор | Смысл |
|---|---|
| `&` | и |
| `\|` | или |
| `~` | не |

> [!warning] Скобки
> Каждое условие берётся в скобки: `(df['Year'] < 1950) & (df['AutoTransmission'] == True)`.

Так можно искать **противоречивые записи** (например, автомат у машины до 1950 года).

Пример: средняя цена Toyota Land Cruiser Prado 2012 года с автоматической коробкой:

```python
df_selet = df[
    (df['AutoTransmission'] == True) &
    (df['Make'] == 'Toyota') &
    (df['Year'] == 2012) &
    (df['Model'] == 'Land Cruiser Prado')
]
df_selet['Price(euro)'].mean()
```

### 4.4. `query` — SQL-подобный запрос

То же самое строкой:

```python
df.query(
    "AutoTransmission == True and "
    "Make == 'Toyota' and "
    "Year == 2012 and "
    "Model == 'Land Cruiser Prado'"
)['Price(euro)'].mean()
```

В `query` условия соединяются словами `and`, `or`, `not` и записываются одной строкой.

## 5. Предобработка `DataFrame`

### 5.1. Удаление дубликатов

```python
df = df.drop_duplicates()          # убрать повторяющиеся строки
df = df.reset_index(drop=True)     # пересчитать индекс 0, 1, 2, ...
```

`reset_index(drop=True)` нужен, потому что после удаления строк в индексе остаются «дыры», а старый индекс иначе добавился бы отдельным столбцом.

### 5.2. Пропуски

```python
df = df.dropna()                   # удалить строки с пропусками
df = df.reset_index(drop=True)
```

> [!warning] Удаление пропусков нужно обосновывать
> В реальных задачах удаление пропусков требует обоснования. Иногда пропуски лучше **заполнить**, чем удалить (по ближайшим по смыслу значениям). Если значение обоснованно заполнить не удаётся — тогда удалить.

### 5.3. Создание своих столбцов

Зная суть данных, можно добавить признак, которого не хватает.

```python
df['Age'] = df.Year.max() + 1 - df.Year   # возраст автомобиля
df['km_year'] = df.Distance / df.Age      # пробег в год
```

- Операции со столбцами поэлементные — как в NumPy.
- Обращение к столбцу через точку (`df.Year`) работает, если в названии нет пробелов и спецсимволов; `df['Price(euro)']` — только через скобки.

#### `map` — замена значений по словарю

Применяет соответствие к каждому элементу столбца:

```python
d = {True: 'Automatic', False: 'Manual'}
df['Transmission'] = df['AutoTransmission'].map(d)
```

#### `apply` — своя функция к каждому элементу

Пример: категория пробега в год — небольшой (до 10 000), средний (10 000–30 000), большой (свыше):

```python
def km_year_category(km_year):
    if km_year <= 10_000:
        return 'Small'
    elif km_year > 10_000 and km_year <= 30_000:
        return 'Medium'
    else:
        return 'Large'

df['km_year_cat'] = df['km_year'].apply(km_year_category)
```

`apply` берёт столбец и применяет к каждому значению функцию, переданную как аргумент.

### 5.4. Удаление лишних столбцов

```python
df = df.drop(columns=['Age', 'AutoTransmission'])
```

(Удаляем то, что уже использовано или заменено: возраст, булев признак, который заменён строковым `Transmission`.)

### 5.5. Удаление строк по индексам из фильтра

Схема: выбрать маской «плохие» строки → удалить их по индексу.

```python
bad = df[(df.Year < 2021) & (df.Distance < 1100)]
df = df.drop(bad.index)
```

Критерии, использованные в ноутбуке:

| Тип | Условие |
|---|---|
| здравый смысл | `Year < 2021` и `Distance < 1100` (почти нулевой пробег у не новой машины) |
| редкие значения | `Distance > 1e6` |
| здравый смысл | объём двигателя `< 200` или `> 5000` см³ |
| здравый смысл | цена `< 101` или `> 5e5` евро |
| редкие значения | `Year < 1951` |

После фильтрации — снова `df = df.reset_index(drop=True)`.

> [!tip] Проверяй, сколько осталось
> После каждой фильтрации полезно смотреть `df.shape`, чтобы понимать, сколько записей потеряно.

### 5.6. Переименование столбцов

```python
df = df.rename(columns={'Engine_capacity(cm3)': 'Engine', 'Price(euro)': 'Price'})
```

> [!note] Порядок действий
> После переименования старые названия (`'Price(euro)'`) больше не работают — все фильтры по ним нужно выполнить **до** `rename`.

### 5.7. Редкие значения в категориальных столбцах

Если в категориальном признаке слишком много значений, редкие можно объединить в одно — `Rare` (без существенной потери точности).

Алгоритм (на примере `Make`, порог 1%):

```python
counts = df['Make'].value_counts()   # частоты значений
freqs  = counts / sum(counts)        # доли

rare = counts[freqs <= 0.01]         # значения, встречающиеся в ≤ 1% записей

df['Make'] = df['Make'].replace(rare.index.values, 'Rare')
df['Make'].value_counts()            # проверка результата
```

- `counts[freqs <= 0.01]` — это логическая маска по `Series`.
- `rare.index.values` — сами названия редких категорий.
- `replace(что, на_что)` — заменяет перечисленные значения на `'Rare'`.

### 5.8. Сохранение результата

```python
df.to_csv('cars_processed.csv', index=False)
```

`index=False` — не записывать индекс строк в файл как отдельный столбец. Обработанные `DataFrame` рекомендуется сохранять.

## 6. Шпаргалка

| Задача | Код |
|---|---|
| загрузить CSV | `pd.read_csv(path)` |
| начало / конец / случайные | `df.head(n)`, `df.tail(n)`, `df.sample(n)` |
| размер, столбцы, типы | `df.shape`, `df.columns`, `df.dtypes` |
| сводка и пропуски | `df.info()`, `df.isna().sum()` |
| число дубликатов | `df.duplicated().sum()` |
| частоты категорий | `df['col'].value_counts()` |
| сортировка | `df.sort_values(by='col', ascending=False)` |
| столбец / несколько столбцов | `df['col']` / `df[['a', 'b']]` |
| по названию / по номеру | `df.loc[...]` / `df.iloc[...]` |
| фильтр по условию | `df[(c1) & (c2)]`, `df[~c]` |
| фильтр запросом | `df.query("A == 1 and B == 'x'")` |
| убрать дубликаты | `df.drop_duplicates()` |
| убрать пропуски | `df.dropna()` |
| пересчитать индекс | `df.reset_index(drop=True)` |
| новый столбец | `df['new'] = выражение` |
| замена по словарю | `df['col'].map(dict)` |
| своя функция | `df['col'].apply(func)` |
| удалить столбцы | `df.drop(columns=[...])` |
| удалить строки по индексу | `df.drop(idx)` |
| переименовать | `df.rename(columns={старое: новое})` |
| заменить значения | `df['col'].replace(список, 'Rare')` |
| сохранить | `df.to_csv('file.csv', index=False)` |

## 7. Типичный порядок предобработки

1. Загрузить данные, посмотреть `head`, `shape`, `info`.
2. Проверить пропуски (`isna().sum()`) и дубликаты (`duplicated().sum()`).
3. Удалить дубликаты, обработать пропуски (заполнить или удалить с обоснованием).
4. Создать новые признаки (`Age`, `km_year`, категории через `map`/`apply`).
5. Отфильтровать противоречивые записи и выбросы; проверить `shape`.
6. Убрать лишние столбцы, переименовать нужные.
7. Объединить редкие категории в `Rare`.
8. Сохранить результат в `.csv`.
