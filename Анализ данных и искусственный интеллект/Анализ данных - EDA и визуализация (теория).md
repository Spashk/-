## 1. Что такое EDA

**Разведочный (исследовательский) анализ данных, EDA** (*Exploratory Data Analysis*) — этап работы с данными **до** построения сложных моделей. Включает анализ основных свойств данных, поиск закономерностей, распределений и аномалий, постановку начальных гипотез, часто с визуализацией.

### Цели EDA

| Цель | Что делаем |
|---|---|
| **Понять структуру и характеристики набора** | размер, типы переменных, пропуски, дубликаты |
| **Найти редкие и нестандартные значения** | аномалии и выбросы: ошибки ввода, случайные события, системные проблемы сбора данных. Их нужно выявить и обработать, иначе пострадает надёжность выводов |
| **Найти связи (корреляции) между переменными** | как одни факторы влияют на другие; отправная точка для гипотез |
| **Подготовить данные к дальнейшим этапам** | очистка от шума, заполнение пропусков, масштабирование и преобразования переменных |

Результатом EDA могут быть: удаление аномалий, заполнение или удаление пропусков, визуализации, выделение или преобразование признаков, удаление шумов и нерегулярных значений.

## 3. Сводный анализ признаков

Часто аналитику нужно дать **агрегированные или сгруппированные** данные: они показывают общие характеристики в нужных разрезах и нередко достаточны для решения бизнес-задачи. Также сводный анализ помогает найти **самые редкие записи и комбинации** значений.

### 3.1. Типы признаков и описательные статистики

**Категориальные переменные** — выражены ограниченным набором значений (группа крови, семейное положение).

```python
num_columns = df.select_dtypes(include='number').columns
cat_columns = df.select_dtypes(include=['object', 'bool']).columns
```

```python
df.describe()                                   # числовые: count, mean, std, min, 25%, 50%, 75%, max
df.describe(include=['object', 'bool'])         # категориальные: count, unique, top, freq
```

- Для числовых признаков `describe` даёт среднее, стандартное отклонение, минимум, максимум и квартили (25% / 50% / 75%).
- Для категориальных — число уникальных значений, самое частое значение (`top`) и его частоту (`freq`).

> [!example] Что видно в этом наборе
> - Самый частый год — 2009, максимальный — 2021.
> - Основная масса автомобилей в диапазоне ~2004–2014 (2009 ± 5 лет).
> - Автомобили сильно старше 2004 года, вероятно, не интересны для задачи (можно взять 1,5 размаха: ~1996–2021).

### 3.2. Группировка `groupby`

Общая схема:

```python
df.groupby(by=grouping_columns)[columns_to_show].function()
```

1. `groupby` группирует данные по признаку (или набору признаков) `grouping_columns`.
2. Выбираются нужные столбцы `columns_to_show`.
3. К полученным группам применяется функция (или несколько).

```python
df.groupby(['Model', 'Year'])[['Price']].mean()           # средняя цена по модели и году

# самые дорогие марки
df.groupby('Make')['Price'].mean().sort_values(ascending=False).head(10)

# несколько функций сразу — метод agg
df.groupby('Make')['Year'].agg(['count', 'min', 'max'])
```

- `agg` позволяет применить **сразу несколько** функций (число записей, минимум, максимум).
- Результат `groupby` имеет в индексе значения группирующего признака (например, годы).

### 3.3. Сводные таблицы `pivot_table`

**Pivot-анализ** — построение сводных таблиц.

```python
pd.pivot_table(df, index=['Make', 'Year'], columns=['Style'],
               values='Price', aggfunc='mean', fill_value=0)
```

| Параметр | Смысл |
|---|---|
| `data` (первый аргумент) | исходные данные |
| `index` | группировка по строкам |
| `columns` | группировка по столбцам |
| `values` | какой столбец агрегировать |
| `aggfunc` | функция агрегации; `'size'` просто считает число строк в группе, `'mean'` — среднее значение |
| `fill_value` | чем заменить отсутствующие значения (`NaN`), например `0` |

Пример: популярность типов кузова по маркам — `index='Make'`, `columns='Style'`, `aggfunc='size'`.

К результату можно обращаться через `loc` и `iloc`:

```python
pivot_style.loc[['Toyota', 'BMW']]        # сводка по маркам
pivot_style.loc['Toyota', 'Sedan']        # число седанов Toyota
pivot_style.sum(axis=0)                   # итог по каждому типу кузова
pivot_style.sort_values(by='Sedan', ascending=False)   # у кого больше всего седанов
```

Сводка по нескольким параметрам помогает искать аномалии (например, какие кузова в каких марках и годах встречаются).

### 3.4. Три способа получить сводную таблицу

| Способ | Особенности |
|---|---|
| **`groupby()` + `unstack()`** | самый гибкий (можно добавлять операции, детальную группировку), но менее читаемый |
| **`crosstab()`** | простой, но не гибкий: только подсчёт значений |
| **`pivot_table()`** | агрегирует по **значениям** (`mean`, `sum`, …), а не только считает |

```python
# groupby с unstack
df.groupby(['Make', 'Year', 'Style']).size().unstack(fill_value=0)

# crosstab
pd.crosstab(index=[df['Make'], df['Year']], columns=df['Style'])

# pivot_table
pd.pivot_table(df, index=['Make', 'Year'], columns='Style', aggfunc='size', fill_value=0)
```

### 3.5. Принцип «Garbage in, garbage out»

> [!important] Garbage in, garbage out
> Чем **чище** база данных и чем **меньше разница** в числе экземпляров каждого класса, тем выше точность итогового предсказания. Мусор на входе даёт мусор на выходе.

Практика очистки по сводным таблицам:
- **Редкие комбинации**, не соответствующие здравому смыслу, фильтруют.
- **Близкие категории объединяют** (например, `Roadster` и `Cabriolet` → `Cabriolet/Roadster`, так как родстеров в базе единицы и десятки):

```python
idxs = (df['Style'] == 'Roadster') | (df['Style'] == 'Cabriolet')
df.loc[idxs, 'Style'] = 'Cabriolet/Roadster'
```

### 3.6. Гистограмма как сводка

**Гистограмма** — представление распределения набора данных по переменной `X`: значения `X` разбиваются на равные интервалы и подсчитывается число значений в каждом интервале. Таблица «число автомобилей за каждый 10-летний период» — это гистограмма в виде таблицы.

### 3.7. Наивный прогноз по группе и метрика MAE

Самое простое («наивное») решение задачи предсказания — **среднее значение по группе**.

- Строим pivot со средней ценой по марке и году.
- Берём среднюю цену группы как **оценку цены**.
- Качество оцениваем **средним абсолютным отклонением** от реальных значений — метрикой **MAE** (*mean absolute error*):

$$MAE = \frac{1}{N}\sum_{i=1}^{N}\left|x_i - \mu(x)\right|$$

```python
# pivot: средняя цена по марке и году
pivot_make = pd.pivot_table(df, index='Make', columns='Year',
                            values='Price', aggfunc='mean')

# MAE для одной марки за период
filtered_df = df[(df['Make'] == make) & (df['Year'].isin(years))].copy()
filtered_df['mean_by_year'] = filtered_df['Year'].map(pivot_make.loc[make])
mae = (filtered_df['Price'] - filtered_df['mean_by_year']).abs().mean()
```

- `isin(список)` — маска «значение входит в список».
- `map(Series)` — подставляет значения по совпадению с индексом.

**`transform`** — применяет функцию к группам и возвращает результат **той же длины, что исходная таблица** (удобно для MAE по всему набору):

```python
df['mean_make_price_by_year'] = df.groupby(['Make', 'Year'])['Price'].transform('mean')
mae = (df['mean_make_price_by_year'] - df['Price']).abs().mean()
```

> [!warning] Оценка занижена
> Такое значение MAE получается **заниженным**: среднее по группе считается на тех же данных, на которых потом измеряется ошибка.

Другая метрика — **MAPE** (средняя процентная ошибка): в некоторых случаях понятнее, чем MAE.

### 5.4. Box plot («ящик с усами»)

![[eda_box_year_before.png|800]]

Элементы box plot:

| Элемент | Смысл |
|---|---|
| **коробка** | интерквартильный размах: от $Q_1$ (25-й перцентиль) до $Q_3$ (75-й перцентиль) |
| **черта в коробке** | **медиана** (50%) |
| **усы** | весь разброс значений **кроме выбросов**: границы $(Q_1 - 1.5\cdot IQR,\; Q_3 + 1.5\cdot IQR)$ |
| **точки за усами** | **выбросы** (*outliers*) |

где $IQR = Q_3 - Q_1$ — интерквартильный размах.

> [!important] Правило выбросов
> Всё, что достаточно далеко за усами, — выбросы. В этом наборе по `Year` выбросами оказываются года примерно до 1970.

## 6. Интерактивная визуализация: `plotly`

**Plotly** — библиотека для **интерактивной** визуализации: графики можно масштабировать, перемещать и настраивать мышью; поддерживаются 3D-графики и географические карты; удобно встраивать в веб-приложения и дашборды. Примеры — [галерея plotly](https://plotly.com/python/).

```python
import plotly.express as px
import plotly.graph_objects as go
from plotly.subplots import make_subplots
```

### Основные функции `plotly.express`

| Функция | Что строит |
|---|---|
| `px.scatter(df, x, y, color, hover_data, ...)` | диаграмма рассеяния |
| `px.box(df, x, y, color, ...)` | box plot |
| `px.histogram(df, x, color, marginal='rug', nbins=..., ...)` | гистограмма с «ковриком» из точек под ней |
| `px.treemap(df, path=[...], values=..., color=...)` | иерархическая «карта плиток» |

```python
fig = px.scatter(
    df, x='Year', y='Price', color='Make',
    hover_data=['Model', 'Distance', 'Fuel_type', df.index],   # что показывать при наведении
    title='Цена vs Год выпуска (цвет — бренд)',
    labels={'Price': 'Цена', 'Year': 'Год выпуска'}
)
fig.update_layout(height=600)
fig.show()
```

![[eda_plotly_scatter_year_price.png|800]]
*Рис. 21. Plotly: цена от года выпуска, цвет — марка (статичный снимок интерактивного графика; в ноутбуке по наведению видны индекс и параметры точки)*

> [!important] Зачем нужна интерактивность в EDA
> При наведении курсора на точку видны её **индекс** и параметры (`hover_data`). Это позволяет быстро найти оставшиеся выбросы и удалить их через `df.drop(индекс)`. Чтобы индекс был доступен в `hover_data`, его при необходимости копируют в отдельный столбец (`df['ID'] = df.index`).

- `marginal='rug'` у гистограммы показывает каждую точку отдельной чёрточкой — удобно искать одиночные выбросы.
- `fig.update_layout(height=..., bargap=...)` — настройка размеров и промежутков.

> [!note] Два графика ниже перерисованы
> В ноутбуке они сохранены только как интерактивные plotly-объекты (без картинки), поэтому здесь они **перерисованы через matplotlib из данных самих графиков**. Оформление отличается от оригинала, но данные те же.

## 7. Шпаргалка

| Задача | Код |
|---|---|
| числовые / категориальные столбцы | `df.select_dtypes(include='number')`, `include=['object','bool']` |
| статистики | `df.describe()`, `df.describe(include=['object','bool'])` |
| группировка | `df.groupby('A')['B'].mean()`, `.agg(['count','min','max'])` |
| значение группы для каждой строки | `groupby(...)['B'].transform('mean')` |
| сводная таблица | `pd.pivot_table(df, index=, columns=, values=, aggfunc=, fill_value=)` |
| подсчёт комбинаций | `pd.crosstab(df['A'], df['B'])` |
| значение в списке | `df['A'].isin([...])` |
| линейный график / столбцы | `s.plot()`, `s.plot(kind='bar')` |
| гистограмма | `sns.histplot(df['A'], bins=, kde=True, hue=)` |
| box plot | `sns.boxplot(data=df, x=, y=)` |
| рассеяние | `sns.scatterplot(data=df, x=, y=, hue=, size=)` |
| тепловая карта | `sns.heatmap(table, annot=True, fmt='d')` |
| несколько графиков | `fig, axes = plt.subplots(r, c, figsize=(w, h))` |
| интерактивный scatter | `px.scatter(df, x=, y=, color=, hover_data=[...])` |
| удалить выбросы | `df.drop(df[условие].index)` |
